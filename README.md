# かんたん書類メーカー

見積書・請求書・領収書をスマホやパソコンで簡単に作成し、PDFや画像で保存できるウェブアプリです。
個人事業主（業種を問わず）向け。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・計算・PDF作成すべて） |
| `lib/html2canvas.min.js` | 画面を画像にする部品（v1.4.1） |
| `lib/jspdf.umd.min.js` | PDFを作る部品（v2.5.1） |
| `lib/ocr/` | 名刺の写真から文字を読み取る部品（Tesseract.js v6.0.1・日本語/英語データ。Apache-2.0）。ボタンを押したときだけ読み込む |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコンの設定 |
| `sw.js` | オフラインでも使えるようにする仕組み（サービスワーカー） |
| `icons/` | アプリのアイコン |

## 動かし方

- いちばん簡単：`index.html` をダブルクリックしてブラウザで開く（オフライン機能は動きません）
- 本番と同じ動き：このフォルダでローカルサーバーを起動して `http://localhost:8000` を開く
  - 例：`python -m http.server 8000`

## 主な機能

- 書類の種類（見積書／請求書／領収書）をボタンで切り替え。入力内容は共通
- 明細：数量・単位・単価・税率（10%／8%軽減／なし）。税抜入力・税込入力を選択
- 値引き：金額または％。消費税をかけず、税込の合計からそのまま差し引く
- 源泉徴収税の差し引き（100万円以下 10.21%、超える部分 20.42%）
- 「話してまとめて入力」：音声入力した文章（例「ロゴ制作 1式 3万円」）を品目・数量・単価に自動分割
- 宛先の登録・呼び出し
- 名刺の写真から宛先（会社名・お名前・住所）を読み取って入力（無料。読み取りは端末の中だけで行い、写真は外に送らない）
- 取引日（期間指定可・表示ON/OFF）、インボイス登録番号、振込先、印鑑画像
- 書類番号の自動採番（例 SK-202611-001）
- 保存した書類の一覧・再編集・複製
- PDF／PNG保存（スマホは共有メニュー、パソコンはダウンロード）
- バックアップの書き出し・読み込み（JSONファイル）
- 領収書が税抜5万円以上のとき収入印紙の注意を表示

## データの保存について

すべてのデータは利用者のブラウザ（localStorage）にのみ保存され、サーバーには送られません。名刺の読み取り用データは初回に自分のサイトから読み込み、ブラウザ（IndexedDB）に保存されます。

| キー | 内容 |
|---|---|
| `dm_issuer` | 発行者情報 |
| `dm_stamp` | 印鑑画像（dataURL） |
| `dm_clients` | 登録した宛先 |
| `dm_hist` | 保存した書類 |
| `dm_draft` | 作成中の書類 |
| `dm_counters` | 書類番号の連番 |
| `dm_lastBackup` | 前回バックアップ日時 |

## 税計算のルール

- 消費税は税率ごとに1回だけ計算し、1円未満は切り捨て（インボイス制度の端数処理ルール）
- 値引きがある税率グループは「値引き前の税込小計 − 値引き」から内税で消費税を計算し直す

## 更新するとき

`sw.js` の `VERSION` を変えると、利用者の端末に新しい版が行き渡ります。
